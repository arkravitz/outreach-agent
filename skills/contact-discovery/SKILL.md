# Contact Discovery

Research a permitted official company contact or leadership page using `pipeline research URL`. A published email is required; personal name and role must appear in the source or stay empty. Use a relevant decision maker where evidence supports the role. Review address provenance and recipient geography with `pipeline contact-review`; that command records a human review and does not infer consent. Complete with sourced contact JSON or a documented inability to find a contact.

Run from the Pipeline repository with its virtual environment and the intended PIPELINE_STATE. Core workflows run independently of OpenCode. See [operator setup](../../README.md) for provider configuration and live-action gates.
