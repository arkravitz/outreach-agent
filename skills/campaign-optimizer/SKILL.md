# Campaign Optimizer

Run `pipeline metrics CAMPAIGN` and `pipeline optimize`. Compare qualified prospects, positive replies, meetings, projects and revenue; every reply is not positive. Account for missing cost/time inputs and small samples. Use stable company experiment assignments and change one approved variable at a time. Suggestions do not authorize increased sending limits, broader geography or new offer commitments. Complete with a supported suggestion and the user decision it needs; leave live campaign edits for explicit authorization.

Run from the Pipeline repository with its virtual environment and the intended PIPELINE_STATE. Core workflows run independently of OpenCode. See [operator setup](../../README.md) for provider configuration and live-action gates.
