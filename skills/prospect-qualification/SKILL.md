# Prospect Qualification

Use `pipeline prepare CAMPAIGN SEED_JSON`, then `pipeline inspect CONTACT_ID`. The qualifier returns score, reason and confidence against configured criteria. Quote-backed company facts describe observations; a proposed workflow pain stays a hypothesis. A rejected or low-confidence prospect must not be described as qualified. Completion means a persisted qualification result or an explicit failure for review.

Run from the Pipeline repository with its virtual environment and the intended PIPELINE_STATE. Core workflows run independently of OpenCode. See [operator setup](../../README.md) for provider configuration and live-action gates.
