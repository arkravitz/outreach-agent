# Case Study Builder

Record completed work using `pipeline complete PROJECT_ID --hours N --revenue N --customer-value TEXT --verified-results TEXT`. Distinguish customer reports from measured results. Use `pipeline record-feedback` only for actual customer-provided wording or referrals, then `pipeline case-study PROJECT_ID`. Ask permission before publishing customer details or sending testimonial/referral requests. Complete with verified results and a case-study record marked for publication approval; never fabricate impact or a quote.

Run from the Pipeline repository with its virtual environment and the intended PIPELINE_STATE. Core workflows run independently of OpenCode. See [operator setup](../../README.md) for provider configuration and live-action gates.
